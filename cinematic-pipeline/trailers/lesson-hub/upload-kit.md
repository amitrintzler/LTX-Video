# YouTube upload kit — Lesson Hub trailer

Claude cannot upload to YouTube: no authorised connector in this environment, and the
only browser path that reaches a signed-in Google account caps uploads at 10 MB (this
file is well over that). Uploading is a manual step - same constraint documented in
`examples/ltx25-optionseducator/youtube/upload-kit.md` for the master trailer.

## How to upload

1. Go to **studio.youtube.com**, signed in to the Options Educator channel.
2. **Create → Upload videos**, drag in
   `~/LTX-Renders/trailers/lesson-hub/lesson_hub_trailer.mp4`.
3. Paste the title and description below.
4. No thumbnail prepared yet - pick a strong frame from the "Continue Module" beat
   (~18s in) if you want a custom one, or let YouTube auto-select.
5. Audience: **"No, it's not made for kids."**
6. Visibility: your call - Unlisted first is the safe way to check it on the platform.
7. Add to the **Trailers** playlist.

## Description

A personalized roadmap, not a library dump. The Lesson Hub keeps one active module in
front of you, links it straight to a practice scenario, and unlocks the next module
only once you're ready - across a skill map spanning Foundations, Technical Analysis,
Fundamental Analysis, The Greeks, Options Strategies, and Risk & Execution.

Every lesson is a short storybook first (Module 1 is Storybook Stock Basics), then a
linked simulator drill - so the concept sticks before you're asked to apply it.

This is the actual dashboard, not a mockup.
