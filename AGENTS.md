# Agent Guidance

The reusable local LTX Desktop 2.5 reference is documented in
`cinematic-pipeline/examples/ltx25-desktop-openworld/README.md`.

Start with its preview workflow, serialize local GPU generation, preserve accepted
keyframes and clips with `--reuse-existing`, and run the documented FFmpeg QA before
delivery. Do not treat a slideshow, silent render, empty frame list, or unreadable
model-generated typography as an accepted video.
